# 音效替换说明

## 文件在哪

```
gameAsset/audios/
├─ bgm/            背景音乐（*.ogg）
└─ sfx/            音效（*.ogg）
   ├─ attack_<id>.ogg     单位/建筑开火
   ├─ move_<id>.ogg       单位移动
   ├─ select_<id>.ogg     选中
   ├─ upgrade_<id>.ogg    升级
   ├─ explosion.ogg       爆炸（导弹/炮弹落地）★ 新增
   ├─ heal.ogg            维修/回血 ★ 新增
   ├─ missile_fly.ogg     导弹飞行（喷流轰鸣）★ 新增
   └─ ...
```

`<id>` 与 `data/units.json`、`data/buildings.json` 里的 `id` 对应，例如
`attack_infantry.ogg`、`attack_gunTurret.ogg`、`attack_missile_launcher.ogg`。
个别名字不一致的，在 `scripts/core/AudioManager.cs` 的 `ClipNames` 里有映射表。

## 想换成自己的爆炸音

**最简单：直接替换文件。**

1. 准备一个 `.ogg`（Vorbis）音频，建议 **单声道、44.1kHz、1 秒左右、峰值 -6dB**；
2. 覆盖 `gameAsset/audios/sfx/explosion.ogg`（文件名不要改）；
3. 回到 Godot 编辑器让它重新导入，或者命令行跑一次：

   ```
   Godot_v4.7.2-stable_mono_win64.exe --headless --path "<工程路径>" --import
   ```

4. 运行游戏即生效。

> 用 `.wav` 也可以，但要把代码里的路径一起改（见下一节），或者用 ffmpeg 转一下：
> `ffmpeg -i mine.wav -c:a libvorbis -q:a 5 gameAsset/audios/sfx/explosion.ogg`

## 想重新生成（不用任何素材）

仓库里带了两个合成脚本：

```
# 爆炸
python tools/gen_explosion.py .godot/explosion.wav
ffmpeg -i .godot/explosion.wav -c:a libvorbis -q:a 5 gameAsset/audios/sfx/explosion.ogg

# 维修回血（柔和的上行铃音）
python tools/gen_heal.py .godot/heal.wav
ffmpeg -i .godot/heal.wav -c:a libvorbis -q:a 5 gameAsset/audios/sfx/heal.ogg

# 导弹飞行（喷流轰鸣 + 呼啸）
python tools/gen_missile.py .godot/missile_fly.wav
ffmpeg -i .godot/missile_fly.wav -c:a libvorbis -q:a 5 gameAsset/audios/sfx/missile_fly.ogg
```

`tools/gen_heal.py` 里可调：三音的频率（默认 C6/E6/G6）、`decay`（余音长度）、
`bell()` 里的谐波比例（0.35 / 0.16）、`dur`（默认 0.85 秒）。

脚本里可调的部分（`tools/gen_explosion.py`）：

| 参数 | 作用 |
|---|---|
| `f0 / f1` | 低频“轰”的起始/结束频率（92 → 42 Hz） |
| `cutoff` 的插值数组 | 噪声低通的截止频率曲线，越低越“闷” |
| `boom` 的系数 | 低频分量大小 |
| `click` 的系数 | 起爆“啪”的强度 |
| `np.tanh(mix * 1.6)` | 饱和度，越大越冲 |
| `dur` | 时长（默认 1.05 秒） |

## 代码里改哪些地方

`scripts/core/AudioManager.cs`：

```csharp
public static void PlayExplosion(float volumeScale = 1f)
{
    const string path = "res://gameAsset/audios/sfx/explosion.ogg";  // ← 换路径改这里
    ...
    player.VolumeDb   = Mathf.LinearToDb(Mathf.Clamp(volumeScale, 0.05f, 1.2f));
    player.PitchScale = (float)GD.RandRange(0.9, 1.08);              // ← 音高随机范围
}
```

`scripts/battle/Vfx.cs` 的 `Explosion()`：

```csharp
// 半径越大越响（0.55~1.0）
AudioManager.PlayExplosion(Mathf.Clamp(0.55f + radius * 0.35f, 0.5f, 1.0f));
```

想给别的特效加音效，就在 `Vfx` 对应函数里加一句 `AudioManager.PlaySfx("res://...")`；
`AudioManager` 内部有 8 个 `AudioStreamPlayer` 轮流用，连续触发不会互相打断。

## 加一个全新的音效

1. 把音频放进 `gameAsset/audios/sfx/`，例如 `heal.ogg`；
2. 在 `AudioManager` 里加一个方法（或直接用 `PlaySfx("res://gameAsset/audios/sfx/heal.ogg")`）：

   ```csharp
   public static void PlayHeal() =>
       PlaySfx("res://gameAsset/audios/sfx/heal.ogg");
   ```

3. 在需要的地方调用（例如 `Vfx.Heal()` 开头）。

## 音量总线

工程里有两条总线：`Music`（BGM）和 `SFX`（音效），
见 `AudioManager` 初始化部分；全局音量在 `project.godot` 的音频设置里调。
